# How do I Set Return Policies on My Listings?

Setting return policies on listings displays important information to buyers, including which items can be returned or exchanged and the time frame for returns and exchanges.

Sellers can set different return and exchange policies for each physical listing or use one policy across all physical listings. Buyers see the return policies when viewing listings.

Sellers outside the EU must set a return policy whenever they edit or create a new listing for a physical item, even if the policy says returns or exchanges are not accepted. Not having a return policy may result in listings appearing lower in Etsy search.

## How do I set return and exchange policies?

When creating or managing listings, create a new return policy, choose an existing policy, or use the simple policy template. Policies can also be applied to multiple listings in Listings Manager.

To create a return and exchange policy through Policy settings:

1. Go to Shop Manager.
2. Navigate to Settings.
3. Select Policy settings.
4. Navigate to Returns and exchanges.
5. Select Create Policy.
6. Choose whether to accept returns and/or exchanges for the item.
7. Select the time frame for accepting returns and exchanges.
8. Select Save and apply.
9. Select Publish.

A policy can only be deleted if it is not associated with any active listings.

## How do I change a listing’s return policy?

1. Go to Shop Manager.
2. Select Listings.
3. Select the listing whose policy you want to change.
4. Navigate to Returns and exchanges.
5. Select Change Policy.
6. Select another existing policy, or choose Create Policy to create a new one.

To apply a policy to multiple listings:

1. Go to Shop Manager.
2. Select Listings.
3. Select the listings.
4. Select Editing options.
5. Select Change return & exchange policies.
6. Apply an existing policy or select Create policy.

## How do I use a simple return policy?

The simple return policy template applies these settings:

- Buyers can return or exchange the item.
- Buyers must return it within 30 days of delivery.
- Buyers are responsible for return shipping costs.
- Buyers are responsible for loss in value if an item is not returned in its original condition.

These settings are standard on all returns and are not specific to the simple return policy.

## Do I need to accept returns or exchanges?

Sellers outside the EU must set a return policy for physical listings, but accepting returns or exchanges is optional and based on business needs. A policy saying “no returns accepted” is still a policy.

EU consumer protection laws require some sellers to offer a minimum 14-day return policy on orders shipped to those countries.

## Can digital downloads be returned?

Return or exchange policies cannot be set on digital listings. If a buyer contacts the seller about a digital item, the seller can resolve the issue as appropriate.

## How can I accept returns for optionally customized items?

If an item can be purchased as-is or customized, but returns are accepted only for non-customized orders, explain this in the shop FAQ or listing description.

To edit the shop FAQ:

1. Go to Shop Manager.
2. Select the pencil icon next to the shop name under Sales Channels.
3. Under Frequently asked questions, choose Add an FAQ.
4. Select Custom and personalized orders.
5. In the Answers text box, specify that customized or personalized orders are not accepted for return.
6. Select Save.

The seller can also edit Messages to Buyers to explain the return policy for customized or personalized items.
